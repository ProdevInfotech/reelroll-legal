# reelroll-legal

Hosted legal documents for **ReelRoll** (`com.prodevinfotech.reelroll`), published via GitHub Pages:

- Privacy Policy: https://prodevinfotech.github.io/reelroll-legal/
- Terms of Use: https://prodevinfotech.github.io/reelroll-legal/terms.html

Source of truth for the documents is the app repo (`gallery-flow/app/src/main/assets/legal/`), which also bundles them offline-first. When the app copy changes, copy it here:

- `privacy-policy.html` → `index.html`
- `terms-of-use.html` → `terms.html`
